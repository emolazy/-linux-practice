# 🚀 Мой путь в DevOps: Практический курс

Этот репозиторий содержит практические задания и проекты, выполненные в рамках изучения основ DevOps и системного администрирования. 

**Окружение:** Windows 11, WSL 2 (Ubuntu), VS Code.

---

## ✅ Выполненные темы (Фундамент)

- [x] **Linux (Навигация):** Работа с файлами и папками (`pwd`, `ls`, `cd`, `mkdir`, `cp`, `mv`, `rm`, `cat`, `find`, `grep`).
- [x] **Linux (Система):** Управление пользователями и группами, права доступа (`chmod`, `chown`), работа с процессами и `sudo`.
- [x] **Linux (Службы):** Управление службами через `systemctl`, просмотр логов (`journalctl`, `df`, `du`).
- [x] **SSH:** Генерация SSH-ключей, настройка `known_hosts`, подключение к серверу и передача файлов через `scp`.
- [x] **Bash:** Написание скриптов (переменные, циклы, условия). Создан скрипт автоматического резервного копирования `backup.sh`.
- [x] **Git & GitHub:** Инициализация репозитория, коммиты, работа с ветками (`branch`, `merge`), отправка на удаленный сервер (`push`).
- [x] **CI/CD:** Настроен GitHub Actions (`.github/workflows/ci.yml`) для автоматической проверки Python-кода при каждом пуше.
- [x] **Python:** Создание виртуального окружения (`venv`), работа с библиотеками (`requests`), логирование, скрипт проверки URL (`check_url.py`) и работы с API (`api_test.py`).
- [x] **Docker:** Написание `Dockerfile`, сборка собственного образа и запуск контейнера.
- [x] **Docker Compose:** Оркестрация нескольких контейнеров (Python-приложение + PostgreSQL, а также стек Prometheus + Grafana).
- [x] **Terraform (IaC):** Описание инфраструктуры кодом. Развертывание Nginx-контейнера через `main.tf` (команды `init`, `plan`, `apply`, `destroy`).
- [x] **Ansible:** Автоматизация настройки сервера. Написан `playbook.yml` для установки и запуска Nginx (Inventory, Tasks, Variables).
- [x] **Мониторинг:** Развернут стек Prometheus + Grafana через Docker Compose. Создан первый дашборд с визуализацией метрик (`rate(process_cpu_seconds_total)`).
- [x] **DevSecOps:** Вынос секретов (паролей) из кода в файл `.env`, настройка `.gitignore`. Сканирование Docker-образов на уязвимости с помощью **Trivy**.

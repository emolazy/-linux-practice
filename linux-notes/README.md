# Моя шпаргалка по Linux

## Навигация
- `pwd` — показать текущую папку
- `ls -la` — список файлов
- `cd` — перейти в папку

## Поиск
- `find . -name '*.log'` — найти все логи
- `grep -r 'ERROR' .` — найти ошибки во всех файлах

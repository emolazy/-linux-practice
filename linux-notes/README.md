# 🚀 Мой путь в DevOps: Практический курс и Capstone-проект

Этот репозиторий содержит практические задания, лабораторные работы и итоговый проект (Capstone), выполненные в рамках изучения DevOps, Backend-разработки и автоматизации тестирования (QA).

**Окружение:** Windows 11, WSL 2 (Ubuntu), VS Code, Docker Desktop.

---

## 🏆 Итоговый Capstone-проект (API + DevOps)

В папке `capstone-api` находится полноценный Backend-сервис, полностью обвязанный DevOps-инструментами.

**Стек технологий:**
*   **Backend:** Python, FastAPI, Pydantic (валидация).
*   **База данных:** PostgreSQL, SQLAlchemy (ORM), Alembic (миграции).
*   **Тестирование:** Pytest, SQLite (изолированная БД для тестов).
*   **Контейнеризация:** Docker, Docker Compose (App + DB + Nginx).
*   **Веб-сервер:** Nginx (Reverse Proxy, HTTPS с самоподписанным сертификатом).
*   **CI/CD:** GitHub Actions (автотесты, сборка образа, публикация в GHCR).
*   **Инфраструктура:** Docker Volumes для сохранения данных БД.

**Что реализовано:**
*   Написано REST API с автоматической документацией Swagger.
*   Настроена контейнеризация всего проекта (запуск одной командой `docker compose up -d`).
*   Настроены миграции БД, чтобы структура таблиц обновлялась безопасно.
*   Написаны автотесты (позитивные и негативные сценарии, интеграционные тесты с подменой БД на SQLite).
*   Настроен CI-пайплайн: при каждом `git push` GitHub Actions прогоняет тесты, собирает Docker-образ и пушит его в GitHub Container Registry (`ghcr.io`).
*   Приложение скрыто за Nginx (работает по HTTPS, трафик проксируется внутрь Docker-сети).

## ✅ Выполненные темы (Фундамент)

- [x] **Linux:** Навигация, права доступа (`chmod`, `chown`), управление пользователями, службы (`systemctl`), логи (`journalctl`), сетевые утилиты (`ip`, `ss`, `nslookup`).
- [x] **Bash:** Написание скриптов (переменные, циклы, условия). Создан скрипт автоматического резервного копирования `backup.sh`.
- [x] **Git & GitHub:** Инициализация репозитория, коммиты, работа с ветками (`branch`, `merge`), отправка на удаленный сервер.
- [x] **Docker:** Написание `Dockerfile`, сборка образов, запуск контейнеров.
- [x] **Docker Compose:** Оркестрация нескольких контейнеров (Python + PostgreSQL, а также стек Prometheus + Grafana).
- [x] **Terraform (IaC):** Описание инфраструктуры кодом. Развертывание контейнера через `main.tf`.
- [x] **Ansible:** Автоматизация настройки сервера (Inventory, Tasks, Variables, Playbook).
- [x] **Мониторинг:** Развернут стек Prometheus + Grafana через Docker Compose. Создан дашборд с визуализацией метрик.
- [x] **DevSecOps:** Вынос секретов в `.env`, настройка `.gitignore`. Сканирование образов на уязвимости через **Trivy**.
